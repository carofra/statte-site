Portfolio PDF degli artisti.

Carica qui i file PDF mantenendo questi nomi esatti (tutto minuscolo, trattini al posto degli spazi):

  martina-rotella.pdf
  mozzarella-light.pdf

I percorsi sono collegati in site/data/artists.js tramite il campo portfolioUrl, es. "/portfolio/martina-rotella.pdf".
Per aggiungere il portfolio di un altro artista: carica il PDF qui e imposta portfolioUrl nel suo oggetto in artists.js.
